# Continuum

> Seamless synchronization of your local multimedia library across devices.

Continuum is a self-hosted platform designed to help you organize, synchronize and continue consuming locally stored multimedia from any device.

Whether you're watching a video on your computer or listening to an audiobook on your phone, Continuum keeps your progress, notes and personal metadata synchronized.

---

## Features

### Current

- Local multimedia library
- Playback progress tracking
- Personal ratings
- Personal notes
- Resume playback from the last position

### Planned

- Device synchronization
- Mobile application
- Streaming support
- Offline downloads
- User authentication
- AI-powered search and summaries
- Cloud deployment

---

## Motivation

Modern streaming platforms synchronize playback progress automatically, but locally stored media often lacks this convenience.

Continuum aims to provide a simple, self-hosted solution for managing personal multimedia libraries while keeping playback progress, annotations and metadata synchronized across devices.
